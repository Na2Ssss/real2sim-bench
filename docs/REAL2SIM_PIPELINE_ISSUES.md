# Real2Sim Pipeline Issue Tracker & Evolution Log

Systematic visual + quantitative audit of all 16 real DROID scenes (9 robotics labs) and downstream `Uni-Goal-Bridge DiT` closed-loop policy training. Every defect below was verified via side-by-side `Real | Sim | 50/50 Overlay` audit strips, Robotiq gripper-caliper thickness measurements (`width_cm ≈ 8.5 * (1 - g_hold)`), and per-episode MuJoCo 4.0.1 failure decomposition (`Explosion` vs `NoLift < 3cm` vs `LiftedFail`).

## Standard Pre-Flight Checklist for Every New DROID Scene (v3 Pipeline)

Before adding ANY new DROID scene to Real2Sim-Bench or policy training:
1. **Run Gripper Caliper First**: compute `med_g_hold` and `width_cm = 8.5 * (1 - med_g_hold)`.
   - If `width_cm < 1.2 cm` on a hollow object → use `"grasp_mode": "rim_pinch"`, `"collision_shape": "hollow_cylinder"` / `"hollow_ring"`, `"wall_m": 0.021–0.024`.
   - If object is elongated/lying (`aspect_xy > 2.2`) → use `"collision_shape": "horizontal_capsule"`, `sx = max(0.025, width_cm/100 + 0.004)`, `sy = length_m`, `sz = sx`.
   - If object is squishy/compliant → use compressed `width_caliper`, NOT uncompressed visual bbox width.
2. **Audit Stage-1 Meshes Visually**: if target container is transparent glass, mirror metallic, or white-on-white thin ceramic, set `"use_visual_mesh": false` so the clean 32-segment parametric lathe renderer is used.
3. **Verify `0` `t=0` Explosions & `NoLift` Ratio**: target `expl == 0` (enforced by P1 non-overlap guard) and `NoLift < 15%`.
4. **Always Visually Inspect `inspect_<scene>.png`** (`Real | Sim | 50/50 Overlay`) before merging episodes into the unified training dataset.
